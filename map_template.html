How to read the map

Percentile
IQB checks each requirement against the test at the chosen percentile of the country's tests, ranked from worst to best.
Profile
How the six use cases are weighted in the score. Default weights them equally; No gaming drops gaming; Essential services drops online backup and gaming; Basic access keeps only web browsing and video conferencing; IQB Edu gives full weight to web browsing, video streaming and video conferencing, half weight to audio streaming and online backup, and none to gaming; Custom sets each weight between 0 and 1. Scores, confidence and ranges are recomputed for the chosen weights. Scores under different profiles are not comparable with each other.
Confidence
The probability that the true score is within ±0.05 of the one shown, given the number of tests. Tests are clustered (the same users and networks), so tests are counted as worth one independent test.
Range
When confidence is below 95 %, the 95 % interval of plausible true scores is shown.
Regions
Clicking a country opens its first-level regions (states, provinces), scored with the same rules from the full year 2025. M-Lab works out where each test came from using the tester’s IP address. Sometimes that lookup only gives the country, not the region. Those tests count towards the country’s national score but not towards any regional score; the share of tests that could be placed in a region is shown under each country’s regions. IP-based location is approximate. Mobile operators often route traffic through a few central points, usually in the capital or largest city, so tests can be placed there even when the user is elsewhere.
Minimum number of tests

An IQB score is built from pass/fail checks. For each requirement, such as “download faster than 25 Mbit/s”, the score asks what share of tests passes. That share is the pass rate. At P50 the requirement counts as met if more than 50 % of tests pass. Every pass rate must be known to within ±5 percentage points, with 95 % confidence. Two steps give the number of tests this takes:

  1. Independent tests needed: 384. The standard formula for estimating a share is n = 1.96² × p(1−p) / 0.05². The hardest case is a pass rate of 50 % (p = 0.5), which gives 384.
  2. Times 3 for clustering: 1,153. Tests aren’t independent: the same people and networks run many of them, so a thousand tests carry less information than a thousand independent tests would. Without access to the individual tests, the size of this effect was estimated from how each country’s monthly pass rates move. A monthly pass rate is treated as a true level that changes slowly, plus noise from which tests happened to be run that month. A real change carries over into the next month; noise does not, so it shows up as a jump followed by a jump back. The size of those back-and-forth jumps measures the noise, which is then compared with the noise that the same number of independent tests would produce. Across 1,128 monthly series from countries with fewer than 10,000 tests a month (in larger countries this noise is too small to see), the noise is a median of 2.7 times that amount. Rounded to 3, three real tests count as about one independent one: 384 × 3 = 1,152.4, rounded up to 1,153.
No score
Fewer than upload tests or fewer than download tests, whatever the percentile. For December 2025, the most recent months are pooled until that minimum is reached, up to 12 months; the window is shown with the score.
Income group
World Bank country classification by income level for fiscal year 2027, based on 2025 GNI per capita (Atlas method): low income $1,175 or less, lower-middle $1,176–4,635, upper-middle $4,636–14,375, high income above $14,375. Source: World Bank, World Bank Country and Lending Groups (July 2026), retrieved through the World Bank API on 29 October 2026.
Data: M-Lab NDT percentile tables via the open-source IQB library, January–December 2025; scores use the library's default configuration. Confidence, ranges and pooling windows: Pulse project, notebooks 1a-sample-size and 5-map (posterior over pass rates, design effect estimated from monthly data).
